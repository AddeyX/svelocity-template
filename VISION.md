# VISION.md

> A runnable skeleton for a SvelteKit, Convex, and Cloudflare product.

## The problem

A new app should not start from an empty directory and a pile of decisions that three production repos already made.

## What this is

Stack is the shared shape: a product Worker, a public Worker, and one Convex backend. The demo is a private note list and a public waitlist so the first `pnpm dev` has a screen.

## What this refuses

Features get added when a real product needs them. The template does not grow an editor, a billing system, or a native shell in order to look complete.
